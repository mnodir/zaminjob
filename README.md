# ZaminJob — AI Agro-Savdo, Eksport va Xizmatlar Platformasi

O'zbekiston dehqonlari, tadbirkorlari va chet ellik xaridorlarni birlashtiruvchi **AI Savdo va Xizmatlar** MVP platformasi.

## Asosiy imkoniyatlar
- **ZaminJob AI Matching & Solishtirma Jadval:** Oddiy matndan mos eksport lotlari, bo'sh yer/issiqxonalar, agro-texnika yoki mutaxassislarni `% mos` ko'rsatkichi bilan solishtirib topadi.
- **AI Eksport Tijorat Taklifi va Shartnoma Generatori (`EN / RU / UZ`):** Dehqon lotidan 1 bosishda chet ellik xaridorlar uchun tayyor B2B tijorat taklifi yaratadi.
- **AI Narx va Eksport Maslahatchisi:** Dehqon yangi lot joylaganda eksport narxi va talab yuqori davlatlar bo'yicha tavsiya beradi.
- **4 ta asosiy bo'lim:** Agro-Savdo & Eksport, Yer va Issiqxonalar, Agro-Texnika va Mutaxassislar, Shaxsiy Kabinet (`Dehqon` / `Tadbirkor` + `PRO` rejimi).

## Ishga tushirish
```bash
python3 -m http.server 8000
```
Brauzerda `http://localhost:8000` manzilini oching.
