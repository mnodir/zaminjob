# ZaminJob — Loyiha Papka Tuzilmasi va Qo'llanma

## Papka tarkibi
- `index.html` — Asosiy sahifa («Sizga kim kerak?» AI qidiruvi, Media galereya, Agro-Pasport, Eksport Pasporti, VMQ-806 bitim).
- `css/style.css` — Dalada quyosh nuri ostida aniq ko'rinadigan yuqori kontrastli dizayn uslublari.
- `js/data.js` — Mutaxassislar, brigadalar, media fayllar va eksportchilar bazasi.
- `js/ai-engine.js` — Foydalanuvchi so'rovidan kerakli kasbni aniqlovchi AI moduli.
- `js/app.js` — Interfeys, media ko'rish oynasi, valyuta konvertori va oflayn rejim boshqaruvi.
- `manifest.json` va `sw.js` — Saytni telefonga o'rnatish (PWA) va keyinchalik Android APK ga o'tkazish fayllari.
- `assets/icons/logo.svg` — ZaminJob vektor logotipi.

## Ishga tushirish
`zaminjob` papkasini ochib, `index.html` faylini istalgan brauzerda (Chrome, Edge, Safari) ishga tushiring.
